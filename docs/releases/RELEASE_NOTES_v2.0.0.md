# 边框实验室 v2.0.0 正式版

本次为界面大版本更新，照片处理流程、模板默认参数与导出结果保持原有表现。

## 界面

- 全新 macOS 风格界面：中性灰白层次、细分隔线、简洁工具栏，减少多余容器与装饰。
- 新增深色 / 浅色模式切换，入口位于左侧品牌区右上角，选择自动保存。主题只影响界面，不影响成片颜色。
- 统一按钮、图标、复选框和下拉菜单样式，移除预览照片外围阴影。
- 更新应用图标：保留原有边框与圆点标识，改用浅灰与石墨灰配色。

## 模板与导出

- 纯白框模板新增照片描边开关，描边样式与经典白框一致，预览与导出同时生效。
- 字体下拉菜单加宽，字体名称单行完整显示。
- 完整保留八套模板：白框、纯白框、纸纹明信片、壹印、杂志侧栏、签名水印、哈苏水印、尼康水印。
- 保留 EXIF 读取与等效焦段、预览文字原位编辑、纸纹材质、水印、旋转、批量同步，以及 JPG 与圆角 PNG 导出。

## 下载

- `Border-Lab-2.0.0-Windows-x64.zip`：Windows x64 便携版压缩包，解压后运行 `Border Lab 2.0.0.exe`，无需安装。
- `Border-Lab-2.0.0-source.zip`：源码包。浏览器直接打开 `index.html` 即可使用；桌面版在目录内执行 `npm install` 与 `npm start`。

## 验证

- `app.js`、`main.js`、`preload.js`、`theme.js`、`paper-surface.js` 语法检查通过。
- 1520 / 1166 / 886 / 376 四种窗口宽度下均无横向溢出。
- 八套模板均成功生成导出图片。
- 打包后的 `app.asar` 内文件与源码逐项校验一致。

## 说明

- 从 1.0.x 升级无需迁移数据，模板默认参数保持不变。
- 本版本未提供代码签名，首次运行如出现系统提示，选择「仍要运行」即可。

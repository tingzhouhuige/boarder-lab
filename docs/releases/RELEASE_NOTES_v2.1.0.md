# Border Lab v2.1.0

## 桌面版与网页版

- 新增照片文件夹浏览器，记住上次导入的位置，灰色标记历史照片但不默认勾选。
- 单击单选、Ctrl 切换多选、Shift 连选、Ctrl+Shift 追加区间。
- 大文件夹采用虚拟列表，拖动时显示照片框和文件名，停稳后优先补齐可见照片。
- 空闲时逐张预读缩略图并持久缓存；滚动时暂停，让用户操作优先。
- 新增 Ctrl+Z 撤销、Ctrl+Shift+Z 重做，支持照片增删、参数、文字、模板、旋转、水印、批量同步与恢复默认，保留当前会话最近 100 步编辑历史。
- 新增全屏按钮与版本号，增加底部导出按钮留白。

## Windows 桌面版

- 系统缩略图在独立进程生成，支持中止和超时退出。
- 缩略图缓存保存在应用数据目录，原图变化时重新生成。
- Esc 退出全屏。

## GitHub Pages 网页版

- 使用浏览器 File System Access API 选择文件夹，Web Worker 生成预览，IndexedDB 保存缩略图、上次文件夹与照片位置及水印。
- 完整文件夹体验建议使用桌面 Chrome / Edge；不支持文件夹接口的浏览器仍可通过普通文件选择器导入照片，编辑与撤销重做可用。
- 文件夹权限由浏览器管理，重开网页时可能需要重新授权；清理网站数据或使用隐私模式会影响持久缓存。
- 照片和缩略图在本地处理，不上传到 GitHub 或服务器。

说明：撤销重做只处理应用内编辑状态，不删除已经导出的文件，也不撤销操作系统窗口操作。

网页版：https://tingzhouhuige.github.io/boarder-lab/
